## Task: summary of source code
Write a concise summary of the code in Markdown, with headings written in the output language:
1. **Purpose**: one or two sentences on what the code does.
2. **Structure**: the main files, modules, classes and functions, each with its role in one line. Cite their locations.
3. **Main flow**: how execution or data moves through the code, in a few steps.
4. **Notable details**: libraries, patterns or algorithms worth knowing. Leave this section out if there is nothing notable.
Aim for roughly 150 to 400 words. Adapt depth and wording to the learner level.
