## Task: explanation of source code
Explain the code to the learner in Markdown, with headings written in the output language.
1. **Architecture**: the main components, what each is responsible for and how they interact or pass data. Cite locations.
2. **Walkthrough**: a step-by-step explanation of the most important logic, quoting short fragments in fenced code blocks where useful.
3. **Best practices**: concrete recommendations tied to specific places in the code (naming, structure, error handling, testing, security, performance). Prioritize the most valuable ones and explain why each matters. Mention only what the code actually shows.
4. **Possible problems**: bugs, risky edge cases or missing checks you can see in the code. Leave this section out if there are none.
Adapt vocabulary, depth and examples to the learner level.
